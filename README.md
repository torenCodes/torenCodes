### What's here

**[invest-lab](https://github.com/torenCodes/invest-lab)** — a self-updating stock
research platform. Scheduled GitHub Actions pull price, volume, SEC Form 4 filings, ETF
holdings and news, score every ticker through five independent boards, and commit the
results as JSON, and that commit is the deploy. It grades its own picks in public, misses
included, and a five-year backtest of insider buying overturned how my own model was
weighted.
Live at [theinvestlab.com](https://theinvestlab.com).

**[football-analytics](https://github.com/torenCodes/football-analytics)** — NFL fantasy
and game-pick research built on nflverse play-by-play data. No ML: every projection is
prior production plus a series of small, named, commented adjustments, so any number on
the site can be traced to the reason behind it. The output is the gap against consensus,
not another ranking. Live at [footballforecast.net](https://footballforecast.net).

**[sql-case-studies](https://github.com/torenCodes/sql-case-studies)** — small analyses
that each start from a business question, answer it in SQL, and end in a Power BI report.
So far: what drives video game sales, and which college majors actually pay for
themselves. Databases and reports are included, so every query can be re-run.
